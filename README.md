RIAI is a complete, modern, responsive web application for aspiring entrepreneurs and business owners across India to discover government schemes, evaluate eligibility, analyze official documents, save favorite schemes, find nearby support organizations, and apply through verified official government portals.

## 🚀 Key Features

1. **Official Government Application Portal Redirection**: Pre-redirection application summary displaying scheme name, implementing organization, eligibility status, required documents, financial summary, verified HTTPS URL, and safety disclaimers.
2. **Document Upload & AI Rules Analyzer**: Upload PDF or certificate images (`.pdf`, `.jpg`, `.jpeg`, `.png`) to extract text and view structured rules, regulations, financial obligations, and eligibility requirements across 9 distinct categories, alongside an interactive Document Q&A assistant.
3. **Live Map & Nearby Support**: Interactive Leaflet.js map with OpenStreetMap tiles, GPS geolocation (`Use My Location`), manual district search, and organization detail cards (DIC, MSME-DFO, EDII, Banks) with directions.
4. **Wishlist for Saving Schemes**: Interactive scheme saving, wishlist management, search, state filtering, and zero-duplicate state persistence.
5. **Scheme Explorer & Profile Engine**: Master database of verified Central and State schemes (PMEGP, NEEDS, PMFME, MUDRA, Startup India Seed Fund, PM Vishwakarma) with multi-parameter filtering and preset profile loader.
6. **RIAI AI Assistant**: Multilingual AI chatbot (English, Tamil, Hindi, Telugu, Kannada) providing scheme guidance and rule explanations.
